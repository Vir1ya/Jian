这个文件夹里的 `块名.html` 是块模板：写 `:::信笺 …` 时，块里面的结构按 `信笺.html` 来拼。

- `{{内容}}`：块正文放在这里，必须恰好出现一次
- `{{参数名}}`：块参数的值，比如 `{{署名}}`；`{{名字}}` 是块名
- `{{#参数名}}…{{/参数名}}`：写了这个参数才输出中间这段
- `{{^参数名}}…{{/参数名}}`：没写这个参数才输出
- 模板里可以写 `[[双链]]`，比如 `[[{{署名}}]]`

外层的 `<div class="blk blk-块名">` 由系统生成，模板只管里面。样式照常写在 `theme/custom.css`。
